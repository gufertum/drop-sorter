# Drop Sorter Help

Drop Sorter puts files where they belong. While Finder is the active app, a shelf sits at the bottom
right of the screen. Drop files or folders on it, pick the folder they belong in (Drop Sorter suggests
one), and they move there, renamed if you want, with Undo one click away.

Drop Mover is its little sibling: a standalone app for one fixed folder. Drop files on its icon in
Finder and they move, without Drop Sorter running.
